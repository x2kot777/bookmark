# @ds_nakajima (なかじ / 中島大介@ウェブ職TV) - X 投稿

Author: なかじ / 中島大介@ウェブ職TV (@ds_nakajima)

Tweet text:
Claude Codeでオススメしたい神MCP6選！

1.Chatwork MCP
https://github.com/chatwork/chatwork-mcp-server
ChatworkをAIから操作するためのMCP。AIで定期実行するタスクが完了したときにChatwork宛にメッセージ送信すると、めちゃくちゃ便利。

2.X MCP
https://github.com/xdevplatform/xmcp
Xの操作ができるMCP。Xに投稿したり、Xから投稿を取得したり・・・アイデア次第で使い方は無限大。

3.Ahrefs MCP
https://docs.ahrefs.com/en/mcp/docs/introduction
SEOをやっている人には必須のMCP。SEOerはこれを使うとサイトやキーワード情報をAIが自動取得してくれるから睡眠時間が増えます。

4. Google Analytics MCP
https://github.com/googleanalytics/google-analytics-mcp
GAと連携してデータを取得してくれるMCP。管理するサイト数が増えると定期的にチェックするのがだるいけど、これを入れておくとClaude Codeが自動的にデータをまとめて分析してくれる。

5.Render MCP
https://github.com/render-oss/render-mcp-server
Webアプリのデプロイ先としてよく使われるRenderの操作ができるMCP。Renderをよく使う人は導入必須。Vercel MCP、Cloudflare MCPなどもあるので、使うサービスによって最適なものを導入しよう。

6.WordPress MCP
https://github.com/wordpress/mcp-adapter
WordPressでメディア運営している人は泣いて喜ぶMCP。まだ自分でWordPress管理画面を触ってるの？

7.Slack MCP
https://docs.slack.dev/ai/slack-mcp-server/
Slackと連携できるMCP。リマインドしてくれたりメッセージ送信してくれたりと非常に便利。個人的にChatworkの使用頻度が高いため、逆に使用頻度の低いSlackをサポートしてくれるのは助かる。
