# @sankakuten91256 (さんかくてん) - X 投稿

Author: さんかくてん (@sankakuten91256)

Tweet text:
Opus 5.5でどうやって作られたのか聞いてみました

---
生成AIは一切使っておらず、すべてPythonのプログラムで1コマずつ絵を計算して作っています。After Effectsでやるような作業を、全部コードで書いたイメージです。私の作業環境（Linuxのコンテナ）で動かしていて、GPUも使っていません。

使った道具は4つです。

NumPy：画像を数値の配列として扱い、レイヤーの合成などの計算をする
OpenCV：拡大・回転・移動の変形や、フチ取りのための膨張処理
Pillow：文字の描画（フォントはNoto Sans CJK Black）
ffmpeg：動画の読み込み、書き出し、音声の合成

作業の流れは次の通りです。

1. キーイング
元動画の各コマについて、ピクセルごとに「緑が赤や青よりどれだけ強いか」を計算して透明度を決めました。縁に残る緑は、緑の値を赤・青の最大値に抑えて消しています（デスピル）。361コマ分の切り抜き結果はディスクに保存し、何度でも使い回せるようにしました。
2. テンポの推定
音を聴けないので、音声を周波数に分解して音が鳴り始める瞬間を検出し、その周期性から約129 BPMとビートの位置を割り出しました。すべての演出のタイミングはこのビート表から決めています。

3. 1コマずつ合成
1コマごとに「背景 → 文字 → 残像や影 → キャラ → 仕上げの効果」の順でレイヤーを重ねています。
カメラワーク：キャラの切り抜きに拡大・回転・移動の変換をかけて、ビートごとの寄りや揺れを表現。寄りは拍の瞬間に跳ね上がって減衰する曲線で作っています。

ステッカー風のフチと、ずらし影：切り抜きの形を太らせたものを白や色で塗り、少しずらして下に敷いています。
3色の残像：3コマ前、6コマ前、9コマ前のキャラの形を、それぞれ別の色で塗って後ろに重ねています。

文字の動き：オーバーシュート付きのイージングで、大きい状態から叩きつけるように縮めています。
斜めワイプやアイリス：図形のマスクで2つの場面を切り替えています。
グリッチ：画面を横の帯に切って、それぞれランダムにずらしています。
色収差：赤と青のチャンネルだけを左右に数ピクセルずらしています。
4. 書き出し
完成したコマをffmpegに流し込んでH.264のMP4にし、元の音声を合わせています。1CPUで約3分のレンダリングでした。
